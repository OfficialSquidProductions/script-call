# Call-sheet contacts, logistics, call cards and temperature display

Local feature built on 0.3.14. No release, installation or real-project migration is performed.

## Behavior

- The G-Casper contact column prints entered Director, Producer, UPM, 1st AD and 2nd AD positions without blank gaps. The primary location is removed from that column; a separate shooting-location line preserves the location and address.
- Daily Sheet → Notes & advance has an off-by-default key-position phone option. Phones come from an explicitly selected stable crew ID or one unique exact-name match. An ambiguous, deleted or missing match prints no guessed phone. Position names stay manually editable; linking a record does not rename them. Other contact printing remains independent.
- Cast/crew call cards collapse to names, with search and Collapse all/Expand all. Search matches names, characters, roles and departments, filters without replacing forms, and retains its query during the session. Card disclosure state persists per production/day/person. Call changes retain the existing row anchor, focus and Advanced state.
- Shooting location, parking, basecamp and hospital have independent Maps links/manual addresses. Coordinates remain under Advanced; ancillary coordinates are independent manual fields. Shooting coordinates alone drive solar/weather. Daily parking, basecamp and hospital notes print beneath addresses. Existing legacy basecamp overrides remain usable, including explicit blank overrides.
- Forecasts populate high/low from NWS periods overlapping the shoot-local day. Daytime high and nighttime low are independently nullable; unavailable/stale/mismatched data stays unavailable. An explicit manual override (including blank) or production manual value wins. Old summary-only caches are refreshed.
- Settings → Temperature display chooses Celsius or Fahrenheit. It is saved with the production, travels in portable archives, and becomes the device default for new productions. With no new setting, an existing day's layout unit is honored; the new-production fallback remains Celsius. Saved numeric values remain canonical Celsius; display changes never convert stored values repeatedly. Manual inputs commit on blur/Enter, reject incomplete values without overwriting, and Escape restores the saved value. Forecast precision is retained before display rounding. Explicit °C/°F tokens in narrative weather text convert for display without modifying the source text. Free text without explicit units is retained.
- Newly resolved/issued snapshots use the new presentation. Historical snapshots without its marker retain their original G-Casper/Narrative presentation, and original issued PDF bytes remain the export source.

The three supplied screenshots were inspected, followed by read-only bounded cells/format inspection of the existing authorized G-Casper `CS Back` reference (sheet 1559528113). The back now uses the original three department columns: Production/AD/Continuity/Camera/Sound/Video/Electric/Grip on the left; Make-up/Wardrobe/Art/Construction/Set Decoration/Property/SFX/Medic/VFX/Additional Labor in the middle; office/accounting/casting/post/legal/locations/catering/craft/transport/vehicles on the right. Blank ruled space follows reference proportions. Dark headings, gray department bands, Montserrat/Nunito and no gutters remain. Standard department aliases such as ART, LOCATION SOUND and HAIR & MAKEUP join their proper bands without changing saved departments or call order. Custom departments are retained. Actual content expands and continues, rather than being clipped to two pages. This is a reference-informed layout, not a pixel copy or automatic reclassification of manually assigned crew roles.

No private reference content, artwork or screenshots are shipped. Existing alternate templates and legacy-file compatibility remain.
