Script Call 0.3.3

Signed and notarized for Apple Silicon · macOS 13+. Intel Mac and Windows builds are not yet validated.

Full release notes & checksums · 0.3.3 source code

Reliable native updates

Fixed a resource-permission issue found during the actual native upgrade test: a logo could become unreadable after installer ownership changes. Shipped resources now have normal public read permissions before signing. Version 0.3.2 is superseded.

The native 0.3.1 → 0.3.3 update passed all twelve acceptance checks, preserving edits, saved templates, issued PDF bytes, import identities, the demo, images, and backup behavior.

Release validation

Passed: 56 core checks, 19 desktop checks, 12 G-Casper checks, 11 Production Desk import checks against the source build, 11 against the packaged build, and all 12 native update acceptance checks.

Included in this release

  • G-Casper-style front/back layouts and customizable Original Narrative templates.
  • Production Desk import and reviewed reimport, with manual edits and issued days preserved.
  • The Last Light demo: eight scenes, sixteen shots, three shooting days, and stable shared/import identities. The separately labeled legacy demo also remains included.
  • Signed update metadata, SHA-512 archive verification, platform compatibility checks, native app signature checks, and an explicit save-and-backup step before restarting.

Original code and fictional demo fixtures are MIT licensed. Third-party licenses and branding notices remain in effect.

Updating from a prototype

Older update-disabled prototypes need one manual installation of the latest notarized release. For later updates, choose Download update, then Save, back up & restart.

0.3.0 — Script Call branding

Renamed Call Sheet to Script Call, with the purple SP logo and “A Squid Productions Software” subtitle. Existing project storage, archive formats, saved template choices, issued PDFs, and demo identities remain compatible.
