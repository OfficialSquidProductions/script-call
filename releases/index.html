These notes describe prepared source changes. Public Mac notarization and the real upgrade test remain in progress; no installer is advertised as ready.

0.3.1 — prepared update-enabled release

  • Original code and fictional demo fixtures are public under the MIT license; third-party and branding notices remain in effect.
  • G-Casper-style front/back layouts, Original Narrative templates, and Production Desk import with reviewed reimport.
  • The Last Light and the separately labeled legacy demo remain included with stable scene, shot, and import identities.
  • Signed update metadata, SHA-512 archive checks, compatibility checks, and a save-and-backup step before restarting.

One manual installation establishes the update public key. Later delivery will be marked verified after the actual release and upgrade checks pass.

0.3.0 — Script Call branding

Renamed Call Sheet to Script Call, with the purple SP logo and “A Squid Productions Software” subtitle. Existing project storage, archive formats, saved template choices, issued PDFs, and demo identities are preserved.
