Install on your Mac

  1. Download and open the ZIP archive.
  2. Move Script Call to Applications.
  3. Launch Script Call and set up the blank production, or open your existing project.

If you use an older update-disabled prototype, install this version manually once to establish the trusted update key. Existing project storage, template choices, import identities, and issued PDF bytes remain compatible. Keep an independent project backup.

Install later updates

With automatic checks enabled, Script Call checks after startup and daily. You can also choose Check for updates. Select Download update, then Save, back up & restart when you are ready.

The app verifies signed metadata, the archive checksum, compatibility, and the native app signature. It saves pending edits and creates a local backup before installation.
