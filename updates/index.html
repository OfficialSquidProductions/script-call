Update delivery

Live delivery is being verified

A public signed release and a successful upgrade between two versions are required before automatic delivery is described as complete.

Use Check for updates inside Script Call. The app checks compatibility, verifies the publisher's signed metadata and the archive's SHA-512 checksum, and requires native signature checks.

Downloading and restarting require your choice. Before installation, pending edits are saved and a local database backup is created. Failed or offline checks keep the current app usable.
