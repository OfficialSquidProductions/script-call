Updates

Script Call 0.3.11 is available for Apple Silicon Macs on macOS 13 or later. It is signed and notarized. This release adds recoverable individual Cast/Crew/Location deletion, collapsible location cards, yellow restricted availability and hidden location timezone inputs while retaining saved zones. Original IDs, links and issued PDF bytes remain preserved. Existing Maps links and On Call remain supported; short or opaque Maps links still need manual address entry.

You choose when to install.

  1. With automatic checks enabled, Script Call checks after startup and daily. You can also choose Check for updates.
  2. Review the release notes and select Download update.
  3. Choose Save, back up & restart when you are ready to install.

The app checks compatibility, verifies the publisher’s signed metadata and the archive’s SHA-512 checksum, and requires native signature checks. Pending edits are saved and a local database backup is created. Failed or offline checks keep the current app usable.

Older update-disabled prototypes need one manual installation of the latest release. Download and installation instructions.

Release freshness

Signed update metadata is renewed through the release workflow. The current metadata is valid until November 24, 2026 at 17:58 UTC; an expired check does not establish that your app is current. If a check cannot complete, keep using your installed app and review the published release information.
